# ResearchMind AI 🔬

A multi-agent AI research pipeline powered by **LangGraph + Groq**.

## What it does
1. 🔍 **Search Agent** — Finds recent web information on your topic
2. 📖 **Reader Agent** — Scrapes the most relevant source for deep content
3. ✍️ **Writer Agent** — Drafts a structured research report
4. 🧐 **Critic Agent** — Reviews and scores the report

## Setup
Add your `GROQ_API_KEY` in the **Space Secrets** panel before running.
